# SQL implementation workspace

The maintainer writes schema, migration, synthetic-data, and business-query scripts here. The clean starting point contains no SQL implementation.

Start with [SQL foundations](../docs/lessons/02-sql-foundations.md), then use [the design proposal](../docs/database-design.md) and [requirements](../docs/requirements.md).

Separate schema changes, sample records, and experiments. Document prerequisites, execution order, expected output, rerun behavior, and cleanup for every script. Existing local MySQL objects must be inspected independently of repository contents.
